# 기후시민플랫폼 시뮬레이션

녹색전환연구소 기후시민플랫폼 최종 시안(Figma)을 실제로 눌러 볼 수 있게 만든 체험용 웹사이트예요. 캠페인(실천 · 서명 · 오프라인 모임), 모임, 1.5도 계산기, 관리자 화면까지 시안의 흐름대로 작동하고, 들어온 사람들이 같은 데이터를 함께 써요. 한 사람이 쓴 글 · 서명 · 신청 · 기록이 다른 사람 화면에도 그대로 보여요.

- 접속 주소: **https://minskapo.github.io/climate-citizen-platform-sim/**
- 입장 암호: 저장소에 적지 않아요. 체험할 분께 따로 알려 드려요.
- 시안(Figma)의 예시 내용이 미리 채워져 있어요: 캠페인 11개, 모임 9개, 글 · 댓글 · 서명 · 신청 · 기록. 체험하는 분들이 직접 만든 데이터도 같은 곳에 쌓여요.
- **기준일은 2027년 1월 19일(화)이에요.** 시안의 화면이 이 날을 기준으로 그려져 있어서, 「내 날짜」를 고르지 않으면 모두 이 날짜로 봐요(새해 1.5도 한달살기 모집 중, 한뼘기후공간 1월의 실천 진행 중 …).
- 실제 로그인 · 알림 발송 · 결제는 없어요. 가입은 활동명과 지역만 받고, 알림은 사이트 안 알림함으로 와요.

## 체험 도구 막대 (화면 맨 위 어두운 띠)

실제 플랫폼에는 없는, 체험용 장치예요. 모바일에서는 접혀 있어서 눌러서 펼쳐요. 설정은 이 브라우저에만 적용돼요.

| 항목 | 하는 일 |
|---|---|
| 지금 역할 | 비회원 · 회원 · 모임 운영진 · 관리자 중에서 골라요. 관리자를 고르면 관리자 화면으로 가요. 모임 운영진은 운영할 모임을 함께 골라요. |
| 활동명 「바꾸기」 | 이미 가입한 다른 활동명으로 들어가거나 로그아웃해요. 여러 사람 역할을 한 브라우저에서 번갈아 해 볼 수 있어요. |
| 내 날짜 | 이 브라우저의 「오늘」을 바꿔요. 처음에는 기준일 2027. 1. 19.이에요. −1 · +1 · +7로 옮기고 「기준일로」로 돌아와요. 기록 · 출석 · 마감 같은 날짜 판단이 모두 내 날짜를 따라요. 다른 사람 화면에는 영향이 없어요. |
| 시각 바꾸기 | 모임 당일 출석 시간처럼 시각이 중요한 화면을 볼 때 써요. 「지금으로」로 돌아와요. |
| 체험 데이터 내보내기 · 초기화 (관리자만) | 모든 데이터를 JSON으로 내려받거나, 입장 암호를 다시 넣고 모두 지워요. 초기화는 모든 사람의 데이터가 지워지니 신중히 써요. |

## 추천 체험 순서 (10단계)

창 두 개(또는 일반 창 + 시크릿 창)를 열어 한쪽은 관리자, 한쪽은 회원으로 해 보면 흐름이 잘 보여요.

1. **관리자로 캠페인 만들기**: 가입한 뒤 「지금 역할」을 관리자로 바꾸고 「캠페인 → + 새 캠페인 만들기」에서 실천 캠페인을 만들어요. 모집은 오늘부터, 진행은 일주일 뒤 시작으로 두고 미션을 몇 개 넣은 뒤 「바로 공개」해요.
2. **계산기 해 보기**: 다른 창에서 비회원으로 「1.5도 계산기」를 끝까지 해요(28문항).
3. **회원으로 가입 · 신청**: 결과 화면에서 가입하면 온보딩이 이어져요. 2단계에서 방금 만든 캠페인에 신청해요. 신청 창이 떠도 온보딩 화면에 그대로 머물러요.
4. **날짜 앞당겨 기록하기**: 체험 도구의 「내 날짜」를 진행 시작 뒤로 옮기면 진행 화면이 열려요. 이번 미션을 기록하고 「참가자 게시판에도 인증 올리기」를 켜 둬요.
5. **다른 사람 화면에서 확인**: 관리자 창(내 날짜 그대로)에서 같은 캠페인을 열면 아직 「모집 중」이고, 참가자 게시판에 방금 올린 인증이 보여요.
6. **며칠 기록을 건너뛰어 보기**: 내 날짜를 사흘 이상 넘기면 다시 시작 배너와 미기록 알림이 나와요. 마지막 날로 옮기면 마무리 화면이 열려요.
7. **서명 캠페인**: 관리자로 서명 캠페인을 만들고, 회원 창에서 서명해요. 관리자 「참가자」 화면에서 서명자 명단과 지역별 숫자를 봐요. 서명 마감 뒤로 날짜를 옮기면 전달 결과 화면이 보여요.
8. **오프라인 모임**: 정원을 작게 둔 모임을 만들고 신청해요. 모임 날짜로 내 날짜를 옮기면 QR 출석 화면이 열려요.
9. **모임 만들기 · 운영**: 「모임 → 새 모임 만들기」로 모임을 만들고, 다른 활동명으로 가입 신청한 뒤 「지금 역할: 모임 운영진」으로 승인 · 공지 · 운영진 지정을 해 봐요.
10. **관리자 도구**: 「웹 도구」에서 HTML 블록을 올려 캠페인 화면에 끼워 보고, 「신고」에서 신고된 글을 숨기거나, 참가자 기록을 CSV로 내려받아요.

## 예시 데이터 다시 채우기

`scripts/seed.mjs`가 배포된 Worker의 공개 API로만(입장 → 가입 → 모임 · 캠페인 · 글 · 신청 · 기록 순서로) 시안의 예시 데이터를 넣어요. 각 요청은 `X-Sim-Date`로 기준일(2027. 1. 19.) 전의 날짜를 달고 가요. 초당 10건 이하로 보내고 전체 1,500건 안팎이라 5~10분쯤 걸려요.

```bash
SIM_PASSCODE=<입장 암호> SEED_FORCE=1 node scripts/seed.mjs
```

- 캠페인이나 모임이 하나라도 있으면 아무것도 하지 않고 멈춰요. `SEED_FORCE=1`을 붙이면 관리자로 `/api/sim/reset`을 불러 **모든 체험 데이터를 지운 뒤** 다시 채워요.
- 다른 Worker에 넣으려면 `SEED_API_BASE=<Worker 주소>`를 붙여요.
- 기준일은 `shared/src/date.ts`의 `SIM_BASE_DATE` 하나로 정해요. 웹의 내 날짜 기본값과 Worker의 `X-Sim-Date` 기본값이 모두 이 값을 따라요.

## 개발

```bash
npm install
npm run dev:web        # 웹 (http://localhost:5173/climate-citizen-platform-sim/)
npm run dev:worker     # Worker API (로컬 D1)
npm test               # 단위 테스트 (vitest)
npm run typecheck
npm run build          # web/dist

# 전체 흐름 점검 (시작할 때 대상 Worker의 체험 데이터를 모두 지움)
npx playwright install chromium
E2E_ALLOW_RESET=1 E2E_API_BASE=<지워도 되는 Worker 주소> SIM_PASSCODE=<입장 암호> npx playwright test
QA_SHOTS=1 E2E_ALLOW_RESET=1 E2E_API_BASE=<…> SIM_PASSCODE=<입장 암호> npx playwright test   # 화면 스크린샷도 test-results/qa/에 저장
```

- E2E는 시작할 때 `/api/sim/reset`으로 대상 Worker의 체험 데이터를 모두 지워요(예시 데이터도 지워지니 끝나면 위 명령으로 다시 채워요). `E2E_ALLOW_RESET=1`이 없으면 아무것도 지우지 않고 바로 중단해요. `E2E_API_BASE`를 주지 않으면 배포된 Worker를 쓰니, 실제 체험 중인 사이트에는 돌리지 마세요.

- 웹은 `main`에 push하면 GitHub Actions(`.github/workflows/pages.yml`)가 테스트 후 GitHub Pages로 배포해요.
- Worker는 `npx wrangler deploy --config worker/wrangler.toml`로 배포해요. 마이그레이션은 `npx wrangler d1 migrations apply climate-sim --remote --config worker/wrangler.toml`.
- Worker 비밀값(`SIM_PASSCODE`, `TOKEN_SECRET`)은 `wrangler secret put`으로만 넣어요. 저장소에는 두지 않아요.

## 구조

- `web/` — React + Vite 단일 페이지 앱(HashRouter). 화면별 기능은 `web/src/features/*`, 공통 부품은 `web/src/components`, 체험 상태(역할 · 활동명 · 내 날짜)는 `web/src/lib/sim.ts`에 브라우저별로 저장해요.
- `worker/` — Cloudflare Worker + D1(SQLite) API. 모든 요청은 입장 토큰(`X-Sim-Token`)이 있어야 하고, 역할 · 사용자 · 내 날짜는 `X-Role` · `X-User-Id` · `X-Sim-Date` 헤더로 받아요. 하루 요청이 8만 건을 넘으면 쓰기를 멈춰요(무료 한도 보호).
- `shared/` — 웹과 Worker가 함께 쓰는 코드: 1.5도 계산기(문항 · 계수 · 계산식), 캠페인 상태 · 미션 회차 계산, 날짜 도우미, 설정 검사, 문구 도우미.
- 맞춤 블록 · 페이지형 웹 도구(관리자가 올린 HTML)는 분리된 iframe 샌드박스에서 실행돼요.
- `e2e/` — Playwright 전체 흐름 점검(데스크탑 1440 · 모바일 390).
- 문서: 설계 `docs/superpowers/specs/2026-10-31-climate-citizen-platform-sim-design.md`, 시안 사본(화면별 글 + 그림) `docs/figma/index.md`, 화면 점검표 `docs/qa.md`.

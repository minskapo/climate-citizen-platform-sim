## 화면에 넣지 않는 표기

- 이 프레임 전체가 개발자용 설명(기능명세/개발 메모)이다. 화면에 넣지 않고 구현 기준으로만 읽는다.

## 보이는 텍스트 (위 → 아래, 왼 → 오른)

- 개발 메모 · 첫 방문 → 온보딩 플로우
- · 진입: 홈 히어로 계산기 카드에서 첫 질문의 답을 고르고 「다음」 → D-1p 계산기 화면(= K-1)으로 이동해 2번째 질문부터 이어 간다. 마지막 질문은 「우리 동네에 가장 필요한 정책」 1개 선택.
- · K-2: 결과·비교·분야별 배출은 계산기(웹 도구) 영역, 저장 권유 카드와 추천 캠페인은 플랫폼 영역. 같은 정책을 고른 시민 수는 가입 후 공개.
- · 비회원 결과는 브라우저에 임시 보관 → 가입 직후 계정에 저장(결과, 고른 정책, 측정일).
- · K-4~K-6 온보딩은 첫 가입 때 한 번만 보인다. 각 단계 「건너뛰기」 가능, 건너뛰면 홈으로.
- · K-5 추천 기준: 지역(K-4) · 참여 방식(K-4) · 배출이 가장 많은 분야(K-2) · 고른 정책(K-1). 「신청하기」는 H-1 신청 창을 줄인 형태(출발점 자동 연결, 알림 켜기, 주최 모임 가입 동의)로 띄운다. 「서명하기」도 서명 창을 온보딩 위에 겹쳐 띄우고, 서명을 마치면 K-5에 그대로 머문다(서명 완료 화면 S-2로 넘어가지 않는다).
- · K-6: 신청한 캠페인에 주최 모임이 연결돼 있으면 자동 가입 상태로 표시하고, 지역 모임을 하나 더 권한다.
- · K-7 이후: 「참가자 게시판에 인사하기」 → H-2(신청 완료 · 시작 전) 화면의 게시판으로 이동.
- · 다른 화면에서 계산기로 들어온 경우(K-2b): 상단에 「← ○○로 돌아가기」 띠를 보여 주고, 결과 화면의 주 버튼을 돌아갈 곳으로 바꾼다. 캠페인에서 왔다면 결과를 캠페인 측정(출발점/마무리)으로 함께 저장한다.

흐름
· 홈 첫 질문 → 계산기(K-1) → 결과(K-2) → 가입(카카오 간편 가입 또는 I) → 온보딩 3단계(K-4 지역·방식 → K-5 캠페인 1개 신청 → K-6 모임) → 준비 완료(K-7) → 캠페인 시작 전 화면(H-2).
가입 (I)
· 간편 가입(카카오 · 네이버 · Google) 또는 이메일. 활동명 · 사는 지역(선택) · 필수 2개와 선택 2개 동의. 기존 회원은 쓰던 이메일로 로그인.
온보딩
· 첫 가입 때 한 번만, 언제든 건너뛰기. 계산 결과와 고른 정책은 가입 직후 자동 저장.
계산기에서 돌아가기 (K-2b)
· 다른 화면에서 계산기로 들어오면 「← 돌아가기」 띠와 돌아갈 곳으로 가는 주 버튼을 보여 준다.

## 보이는 텍스트 (위 → 아래, 왼 → 오른)

- 기능명세 · 서명 캠페인
- 흐름 (S → S-1 → S-2 → S-3)
- · 상세에서 요구안 요약과 설명 글(편집기로 쓴 게시물), 오른쪽의 지역별 서명 수 · 목표 달성률을 보고 「서명하기」 → 서명 창(요구안, 함께 내는 정보: 활동명 · 사는 지역, 전달 동의) → 서명 완료(몇 번째 서명, 이어서 해 보세요) → 마감 뒤 전달 결과와 전달처 답변. 「진행 중」 단계와 미션 기록이 없다.
- 공통 틀과 맞춤 영역
- · 요구안 요약 · 설명 글 · 지역별 서명 수(오른쪽 영역) · 목표 달성률 · 전달 결과는 플랫폼 공통 틀이다(M-2s 설정). 맞춤 영역은 위치 ②에 설명 블록만 둔다. 공개 화면에는 서명 수만 보이고, 활동명과 지역은 운영자와 전달처만 본다. 주최 모임 가입은 선택이다.

# 기능명세: 도구

- 노드 ID: `331:1937`
- 스크린샷: `spec-도구.png`

## 화면에 넣지 않는 표기

- 이 프레임 전체가 개발자용 설명(기능명세/개발 메모)이다. 화면에 넣지 않고 구현 기준으로만 읽는다.
- 주석 칩/라벨: 「· 블록형 · 페이지형 HTML은 녹색전환연구소가 관리자 화면(M-3)에서 보안 검토 후 올린다. 사용자는 도구를 올리지 않는다.」

## 보이는 텍스트 (위 → 아래, 왼 → 오른)

- 기능명세 · 1.5도 계산기와 캠페인 자료
- 정의
- · 도구 게시판은 두지 않는다. 사용자 메뉴에는 상단바 오른쪽의 「1.5도 계산기」 버튼 하나만 둔다. 교안 · 활동 자료는 모임 게시판 「자료」 분류에 누구나 올린다(별도 안내 없음).
- 캠페인 자료
- · 캠페인에서 쓰는 파일(진행 가이드 · 감축카드 등)은 관리자가 캠페인 설정(M-2)에서 바로 올리고, 웹 도구(HTML)는 「웹 도구」(M-3)에 올린 것 중에서 고른다. 캠페인 상세의 「이 캠페인에서 쓰는 자료」에 보인다(파일 = 내려받기, 웹 도구 = 열기).
- 웹 도구
- · 블록형 · 페이지형 HTML은 녹색전환연구소가 관리자 화면(M-3)에서 보안 검토 후 올린다. 사용자는 도구를 올리지 않는다.
- 캠페인 전용
- · 「캠페인 전용」 자료와 웹 도구는 해당 캠페인 참가자만 내려받거나 실행한다.
- 계산기 (D-1p)
- · 상단바 「1.5도 계산기」, 홈 계산기 카드, 캠페인 출발점 · 마무리에서 같은 화면을 연다. 「← 이전 화면」으로 연 곳에 돌아간다. 결과는 「내 활동 › 나의 탄소 기록」에 쌓인다.

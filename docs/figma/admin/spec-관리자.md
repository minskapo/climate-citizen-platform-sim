## 보이는 텍스트 (위 → 아래, 왼 → 오른)

기능명세 · 관리자
정의
· 녹색전환연구소 운영자만 쓰는 화면. 사용자 화면과 다른 주소(예: /admin)로 들어가고, 관리자 계정으로만 열린다.
홈 (M)
· 처리할 일(신고 · 협업 제안 · 게시 대기 웹 도구 · 모집 시작 예약)과 운영 현황(회원 · 캠페인 · 모임 · 새 글 · 계산기 측정).
캠페인 (M-1, M-2)
· 캠페인 만들기는 여기에만 있다. 설정에 따라 신청 창(H-1) · 시작 전 체크리스트(H-2) · 진행 화면(H-3) · 마무리(H-4)가 자동으로 구성된다. 유형을 고르면 설정 화면이 바뀐다: 실천(M-2, 미션과 기록) · 서명(M-2s, 요구안 · 목표 인원 · 전달) · 오프라인 모임(M-2o, 장소 · 정원 · 출석 확인). 「복제」로 지난 캠페인 설정을 가져와 새 기수를 만든다.
미션 규격 (모든 캠페인 공통)
· 미션 하나 = 회차 · 분류 · 미션 문구 · 설명 · 기록 항목. 캠페인마다 미션 주기(매일 바뀜 / 주마다 바뀜 / 기간 내내 하나 / 날짜 지정)와 기록 주기(매일 / 주 3회 / 주 1회 / 마무리 때 한 번)를 따로 고른다. 기록 항목은 실천 체크(필수)에 한 줄 메모 · 사진 · 숫자를 더한다. 진행 화면의 미션 이름(오늘의 미션 / 이번 주 미션)과 진행률(기록 n / 전체 m번), 미기록 알림 기준은 이 설정에서 자동으로 정해진다. 미션 목록은 「미션 묶음」으로 저장해 다른 캠페인에서 불러온다.
웹 도구 (M-3)
· 블록형 · 페이지형 HTML과 설명 파일을 올리고, 미리보기 후 게시한다. 이전 버전으로 되돌릴 수 있다. 블록형은 캠페인 설정에서 화면마다 위치(① 맨 위 · ② 공통 정보 다음 · ③ 맨 아래 · 놓지 않음)를 고른다.
신고 · 협업 제안 (M-4)
· 신고는 「숨기기」 또는 「문제 없음」으로 처리. 협업 제안은 답장하거나 「캠페인 초안 만들기」로 M-2를 연다. 협업 제안은 받은 뒤 1일 안에 답변한다(제안 창과 완료 알림에 안내).
그 밖의 메뉴
· 모임(전체 모임 목록, 비공개 모임 확인, 모임 닫기) · 회원(검색, 이용 제한) · 데이터 · 통계(익명 집계 내려받기)는 별도 시안 없이 표 형태로 만든다.
창과 알림
· 확인 · 입력은 화면 위에 뜨는 창으로 열고 ✕ · 취소로 닫는다. 끝나면 짧은 알림이 1.6초 동안 뜬다. 내보내기 · 되돌리기 · 모임 닫기처럼 되돌리기 어려운 일은 빨간 버튼으로 구분한다. 참가자 관리(M-1a)와 웹 도구 미리보기(M-3a)는 별도 화면이다. 참가자 관리는 유형별로 다르다: 실천은 참가자(M-1a), 서명은 서명자(M-1s), 오프라인 모임은 신청 · 출석 명단(M-1o).

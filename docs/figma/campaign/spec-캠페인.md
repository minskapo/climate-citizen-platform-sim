## 보이는 텍스트 (위 → 아래, 왼 → 오른)

- 기능명세 · 캠페인
- 정의
- · 기간이 정해진 함께하는 활동. 유형 3가지(서명 · 실천 · 오프라인 모임), 상태 4가지(모집 예정 · 모집 중 · 진행 중 · 마감). 기간(예: 2주, 4주)은 캠페인마다 정한다. 유형마다 설정 화면이 다르다: 실천(M-2) · 서명(M-2s) · 오프라인 모임(M-2o). 사용자 화면: 실천 H~H-4, 서명 S~S-3, 오프라인 모임 O~O-4.
- 누가 여나
- · 녹색전환연구소만 만든다. 사용자 화면에는 「캠페인 만들기」가 없고 「캠페인 협업 제안」만 있다. 캠페인은 주최 모임을 하나 연결할 수도, 연결하지 않을 수도 있다. 연결하면 주최는 모임 이름으로, 연결하지 않으면 「녹색전환연구소」로 표시한다.
- 카드
- · 태그(유형 · 기간 · 방식) · 이름 1줄 · 주최 모임 · 설명 2줄 · 인원(「N명 참여」, 모집 예정은 「N명 알림 신청」) · 자세히 보기.
- 상세 (H)
- · 공통 틀(머리 · 신청 카드 · 정보 · 쓰는 자료 · 주최 모임 · 참가자 게시판) + 캠페인별 맞춤 영역(연구소가 만든 HTML, 블록형 샌드박스, 주황 점선).
- 참여 흐름
- · 신청 창(H-1) → 시작 전(H-2) → 진행 중(H-3) → 마무리(H-4). 기록이 끊기면 다시 시작 배너(H-3a), 그만두기 전 쉬어 가기 제안(H-3b). 신청 창의 「출발점」과 시작 전 체크리스트는 캠페인 설정에 따라 자동으로 구성되는 공통 항목.
- · 주최 모임을 연결했으면 신청할 때 그 모임에 자동 가입되고(서명은 선택), 모임 게시판에 참가자 전용 캠페인 탭이 생긴다. 연결하지 않았으면 모임 가입 없이 캠페인 안에 참가자 게시판이 따로 생긴다.
